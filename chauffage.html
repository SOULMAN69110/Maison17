Réglages réservés

Pour régler le radiateur depuis cet appareil, colle ton jeton GitHub. Il reste dans ce navigateur seulement, jamais dans le dépôt.

  1. Sur GitHub : Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nom « Chauffage Maison17 », expiration au choix, Only select repositories → Maison17.
  3. Permissions → Repository → Actions : Read and write (rien d'autre), puis Generate token.
